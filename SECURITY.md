# Seguridad

## Reportar una vulnerabilidad

No publiques detalles de una vulnerabilidad en un issue o Pull Request.

Abre un reporte privado a través de la función **Security** del repositorio, si está disponible. Si no lo está, contacta directamente a las personas responsables del repositorio e incluye:

- Una descripción del problema y su impacto.
- Pasos mínimos para reproducirlo.
- La versión o commit afectado.
- Una propuesta de corrección, si la tienes.

No incluyas datos personales, credenciales ni documentos reales en el reporte.

## Alcance

La aplicación está diseñada para ejecutarse en el navegador y guardar datos de formularios en `localStorage`. Las vulnerabilidades relacionadas con dependencias, generación de archivos o exposición accidental de datos son relevantes para este proyecto.
